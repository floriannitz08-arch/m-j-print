# Rechnungen
Die PDF-Vorschau enthält ausschließlich fiktive Daten und ist keine Rechnung.
Vor Freigabe: Betreiberanschrift, Steuerstatus, Steuernummer/USt-ID soweit erforderlich, fortlaufende Rechnungsnummern, Leistungsdatum, tatsächliche Positionen, Versand, Steuerbeträge und Korrekturprozesse konfigurieren. Rechnungen unveränderlich speichern und Zugriff auf den jeweiligen Kunden begrenzen. Anforderungen an elektronische Rechnungen für B2B gesondert prüfen. Keine automatische Ausstellung vor Freigabe.
