Hosting af hjemmesiden

Hjemmesiden hostes på GitHub Pages. Tekniske oplysninger såsom IP-adresse, tidspunkt, anmodede ressourcer og browseroplysninger kan behandles af hostingudbyderen med henblik på drift og sikkerhed. GDPR artikel 6, stk. 1, litra f, kan være behandlingsgrundlag. Se GitHubs privatlivspolitik. Behandling uden for EØS, især i USA, er mulig. Konkrete opbevaringsperioder og overførselsgarantier skal endnu afklares.

Cookies og analyse

Hjemmesidens egen kode anvender ikke cookies, analyse- eller reklamescripts, kundekonti eller onlinebestillingsformularer. Animationer afvikles lokalt i browseren.

Telefoniske henvendelser og bestillinger

Kontaktoplysninger og oplysninger om henvendelsen kan behandles. GDPR artikel 6, stk. 1, litra b, gælder ved nødvendige foranstaltninger før aftaleindgåelse eller opfyldelse af en aftale; litra f kan gælde ved andre henvendelser. Nødvendige bestillingsoplysninger kan videregives til fragtfirmaer. Lovpligtig opbevaring kan kræve yderligere lagring efter litra c. Oplysninger slettes som udgangspunkt, når formålet ophører, medmindre opbevaringspligt gælder.

Dine rettigheder

Efter GDPR har du ret til indsigt, berigtigelse, sletning, begrænsning, dataportabilitet og indsigelse mod behandling baseret på legitime interesser. Samtykke kan trækkes tilbage med fremadrettet virkning. Du kan klage til en tilsynsmyndighed, eksempelvis datatilsynet i Schleswig-Holstein.

Oplysninger om hosting og virksomhedens behandling af personoplysninger skal endnu gennemgås endeligt af den dataansvarlige.
